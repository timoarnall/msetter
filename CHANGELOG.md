# Changelog

One line per publish, newest first: the version, the date, and what changed. The version is the one in `VERSION`.

- 1.0.0 (2026-11-19): the project page no longer bounces sideways on a phone; the Copyright in files help line, the app's description and three lines in the docs use plainer words.
- 1.0.0 (2026-11-19): the project page and README say what Msetter does: see your profiles side by side, keep profiles and cameras in sync, set fiddly settings in the right profiles, start from profiles based on what pros do. The app is unchanged.
- 1.0.0 (2026-11-19): first release. Profiles from a library, side by side, with every change marked by a tick and a red dot that mean the same thing everywhere; nothing drawn over a value or cut; no camera chosen until you choose one; Save in the order things happen, with a way back to the camera's own file; the library remade as a set of arguments for how an M can be set up; About, a version, and what to do if something goes wrong.
