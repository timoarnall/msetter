# Every Q3 code

Generated by `tools/build_q_codes.py` from `docs/leica-q3-codes.json`. Do not edit by hand; edit the JSON and run the script.

Every code a Leica Q3 on firmware 4.1 writes to `settings.lcs`, in the order the camera writes them, with what each is thought to be. Background, sources and how to help: [What about the Q](leica-q.md).

**How sure.** Known: two independent sources agree, or the camera's own USB list confirms it (75 codes). Likely: one strong clue, such as the manual's option list matching the values (222). Guess: a clue that fits but proves nothing, such as a code's neighbors (164). Unknown: no clue yet (125). None of it has been tested by importing an edited file on a Q3.

**Columns.** Kind: number or text, per profile (seven values: the live settings, then profiles 1 to 6) or camera-wide (one value). New: the code is not in files from firmware before 4.0. Q3 43: the same photographer's Q3 43 file holds a different value, because of the lens or the photographer's own choice.

**Words in the evidence.** Hudson, Hudson's profiles: the Q3 and Q3 43 files Hudson Henry shares, with six named profiles (Standard, B&W, LS / Pano, People, Animals, Bracketing). Old file: a Q3 file from before firmware 4, from the Leica Dial & Dot repository; its unsaved profiles hold factory values. USB list: what a Q3 43 on firmware 4.1.1 reports over USB, as published by libgphoto2. M code book, M firmware: the M11 family's own settings tables, for codes the two lines share. SL3 editor, Dial & Dot: two hobby editors, given little weight. Manual: the Leica Q3 instructions.
